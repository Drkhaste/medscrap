# راهنمای نصب و استفاده از اپلیکیشن اندروید Medofast Scraper

این پروژه نسخه اندرویدی اسکرپر مدوفست است که با استفاده از Flutter ساخته شده است.

## نحوه دریافت فایل نصبی (APK) بدون نیاز به نصب نرم‌افزار اضافی

راحت‌ترین راه برای ساخت فایل APK استفاده از **GitHub Actions** است:

1. این مخزن (Repository) را در گیت‌هاب خود آپلود کنید.
2. به تب **Actions** در بالای صفحه گیت‌هاب بروید.
3. گردش‌کار (Workflow) با نام **Flutter Android Build** را انتخاب کنید.
4. دکمه **Run workflow** را بزنید.
5. پس از چند دقیقه، در بخش **Artifacts** می‌توانید فایل `release-apk` را دانلود و روی گوشی خود نصب کنید.

## نحوه استفاده از اپلیکیشن

1. **تنظیمات**: ابتدا به تب **Settings** بروید و آدرس شروع (URL) را وارد کنید.
2. **ورود به سایت**: به تب **Browser** بروید. سایت مدوفست باز می‌شود. نام کاربری و رمز خود را وارد کنید تا وارد پنل شوید.
3. **تایید ورود**: به تب **Scraper** برگردید و دکمه **Confirm Login** را بزنید.
4. **شروع عملیات**: دکمه **Start** را بزنید. اپلیکیشن به صورت خودکار سوالات را باز کرده، گزینه ۱ را انتخاب می‌کند تا پاسخ صحیح نمایش داده شود، و اطلاعات را ذخیره می‌کند.
5. **خروجی**: بعد از اتمام کار، به تب **Export** بروید و دکمه **Convert JSON to CSV** را بزنید تا فایل اکسل (CSV) در حافظه گوشی شما ذخیره شود.

## نکات مهم
- اپلیکیشن برای استخراج داده‌ها از یک مرورگر داخلی استفاده می‌کند.
- سرعت استخراج را می‌توانید از بخش Settings با تغییر Delays تنظیم کنید.
- فایل‌ها در پوشه اسناد (Documents) اپلیکیشن ذخیره می‌شوند.
